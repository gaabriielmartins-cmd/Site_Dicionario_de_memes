Este projeto é um site que o objetivo é ter maior numero de memes de todas épocas, eu usei apenas python no app.py e html no index.html e eu usei um sistema de coleta de dados e um sistema de upload de imagem para o site e site de contas e com login utilizando o google

O que eu gostaria de ter no projeto:
1.Opcão de aceitar, recusar  e de personalizar cookies
2. Verificador de bots para não sobrecarregar a api
3. Maior biblioteca de memes antigos 
4. mais fotos dos memes
5. Verificação de email
6.Criptografia boa enquanto a mensagem viaja
